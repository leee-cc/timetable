# 暨南大学课程表

新闻与传播学院 2026-2027 学年第一学期的研究生课表网页。

**在线访问：<https://leee-cc.github.io/timetable/>**

## 功能

- **正在上课 / 即将上课**：页面顶部实时显示当前状态、剩余时间、进度条；课表中对应时段会高亮并显示角标
- **手机端 / 电脑端切换**：左上角按钮切换，默认手机端
  - 手机端 = 按天查看（星期标签条 + 当天课程卡片）
  - 电脑端 = 周一至周日 × 13 节的完整网格
  - 选择会记住，下次打开保持
- **周次切换**：`‹ ›` 翻周，显示该周的日期区间
- 打印时自动输出电脑端周网格

## 周次换算

第 1 周从 **2026-09-07** 起算，第 2 周为 09-14 ~ 09-20，依次到第 18 周（2027-01-04 ~ 01-10）。页面按此规则把课程周次换算成具体日期。

## 说明

单文件 HTML，无外部依赖，离线也能打开。数据来自《研究生选课.pdf》。

页面本身可以直接用浏览器打开本地文件；本仓库的用途是提供手机可访问的在线地址。
